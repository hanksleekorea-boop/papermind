# 페이퍼마인드 - 통합 범용 서비스 원샷 개발 마스터 플랜 v3.4

## 1. 프로젝트 개요
- **서비스명**: PaperMind
- **목표**: 복잡한 논문과 리서치를 AI로 요약해 드립니다.
- **핵심 기능**: 자동 번역, 핵심 문장 추출, 참고문헌 포맷팅

## 2. 엔진 A/B/C 결합 전략
v3.4 마스터 지침에 따라 기존 기획에 다음 사항을 융합합니다:
- **Engine A**: 일반적인 UI/UX 및 비즈니스 핵심 로직 구현 (10배 정밀도 적용)
- **Engine B**: GitHub 권한 검증, Google 로그인, 무가입 지원, QR/PWA 연동, 프리미엄 기능
- **Engine C**: 공유 저장소, 동시 편집, 오프라인 충돌 방지 로직 (로컬 퍼스트 기반)

## 3. 5단계 상세 개발 계획 (저숙련 AI 무해석 실행용)

### STAGE 1: BASELINE (기반 구축 & PWA)
- [x] 프론트엔드 레포지토리 초기화 및 UI 프레임워크(Tailwind CSS) 적용 완료
- [ ] PWA Manifest 및 Service Worker 뼈대 생성 (오프라인 지원 준비)
- [ ] 정적 호스팅 (Cloudflare Pages) 도메인 연결 (`페이퍼마인드.scanners.cc`)

### STAGE 2: FOUNDATION (인증 및 인프라)
- [ ] Google OAuth, GitHub 권한 검증 통합 로그인 모듈 구축
- [ ] 무료 가입자 DB 스키마 설계 및 내 계정 페이지 구현
- [ ] 인증 세션과 연동된 QR 기반 로그인 보조 수단 적용

### STAGE 3: CORE (비즈니스 로직 & 프리미엄)
- [ ] **자동 번역**, **핵심 문장 추출** 로직 구현
- [ ] 결제 모듈을 제외한 프리미엄 기능 플래그(Feature Toggle) 세팅
- [ ] 외부 파트너 API 및 데이터 소스 Webhook 연동

### STAGE 4: COLLABORATION (공유 및 동시성)
- [ ] **참고문헌 포맷팅** 완벽 구현 및 Edge Case 10,000+ 시나리오 방어
- [ ] 클라우드 기반 공유 저장 및 파일 권한 관리
- [ ] 다중 사용자 동시 편집(CRDT 등) 및 오프라인-온라인 충돌 병합 로직

### STAGE 5: RELEASE (상용화 및 런칭)
- [ ] 프로덕션 DB 마이그레이션 및 2,400+ 품질 매트릭스 검사
- [ ] 오픈 그래프(OG) 메타태그, SEO 및 PWA 인스톨 배너 점검
- [ ] V1.0 최종 배포 및 100% Commercialization Readiness 달성 승인
